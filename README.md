# RandomGame 팀 랜덤 배정

Unity로 만든 팀 랜덤 배정 프로그램입니다. 기본 명단은 18명이며, 실행 화면에서 팀 구성 방식을 바꿀 수 있습니다.

## 팀 구성

- 팀 수: 2~6팀
- 자동 배분: 전체 인원을 가능한 한 균등하게 나눕니다.
  - 18명 / 4팀 → `5,5,4,4`
  - 18명 / 5팀 → `4,4,4,3,3`
  - 18명 / 6팀 → `3,3,3,3,3,3`
- `Custom Team Sizes` 토글: 팀별 인원수를 쉼표, 공백 또는 세미콜론으로 직접 입력합니다.
  - 예: 4팀을 `3,5,4,6`으로 설정
  - 입력 개수는 팀 수와 같아야 합니다.
  - 각 팀은 1명 이상이어야 하며 합계는 전체 명단 인원과 정확히 같아야 합니다.

잘못된 설정은 연출이나 CSV 저장을 시작하기 전에 거부되며 설정 화면에 오류가 표시됩니다.

## 반응형 UI

- 팀 결과 그리드는 화면비와 안전 영역에 맞춰 2~3열로 자동 전환되고, 2~6팀 전체가 화면 안에 들어오도록 크기와 위치를 조정합니다.
- 완료 문구와 종료 버튼은 화면 가장자리나 노치 영역에 잘리지 않도록 별도 안전 영역에 배치됩니다.
- 설정 화면은 가로·세로 크기를 함께 반영해 스케일되며 입력 행, 토글, 버튼과 글자 크기도 작은 화면에 맞게 재배치됩니다.
- 팀 파티클과 이동 라이트는 바뀐 팀 위치와 현재 화면 영역을 따라갑니다.

## 기타 옵션

- 고정 시드: 같은 시드와 설정으로 같은 팀 배정을 재현합니다.
- 깍두기: 플레이어 명단에 포함된 0~3명을 서로 다른 팀에 우선 배치하고, 팀 수보다 많으면 남은 자리가 있는 팀에 순환 배치합니다.
- 결과 저장: 실행 파일 또는 프로젝트 루트의 `Result.csv`에 저장합니다. CSV 멤버 열은 가장 큰 팀 인원수에 맞춰 자동 확장됩니다.

## 기술 구성

- Unity `6000.3.16f1`
- TextMeshPro / Unity UI / URP 2D
- DOTween
- 프로젝트 소유 `ParticleSystem` 및 네이티브 피드백 컴포넌트

FEEL과 Retro Arsenal은 필요하지 않습니다. 유료 패키지 자산이 다시 포함되지 않도록 `.gitignore`의 보호 규칙은 유지합니다. BGM은 선택 사항이며 클립이 없으면 조용히 건너뜁니다.

## 검증

Unity CLI와 Pipeline 패키지가 연결된 상태에서 다음 명령으로 저장된 씬을 검증할 수 있습니다.

```powershell
unity command randomgame_validate_standalone --format json
```

검증기는 Missing Script/Prefab, 유료 패키지 의존성, 6개 팀 연출 슬롯, 설정 UI 바인딩, 기본 팀 구성과 16:9·4:3·울트라와이드·세로 안전 영역 프로필을 확인합니다.
